    ```html
    <!-- Written by hand… and maintained forever -->
    <picture>
        <source type="image/avif" srcset="/images/hero-640.avif 640w, /images/hero-1080.avif 1080w, /images/hero-1920.avif 1920w" sizes="100vw" />
        <source type="image/webp" srcset="/images/hero-640.webp 640w, /images/hero-1080.webp 1080w, /images/hero-1920.webp 1920w" sizes="100vw" />
        <img src="/images/hero-1080.jpg" srcset="/images/hero-640.jpg 640w, /images/hero-1080.jpg 1080w, /images/hero-1920.jpg 1920w"
            sizes="100vw" width="1920" height="1080" loading="lazy" alt="Hero" />
    </picture>
    ```
    </TabItem>

## One source, every variant

The same photo, 800 px wide, in the three default formats. The browser downloads the first one it supports.
